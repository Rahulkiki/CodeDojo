# ⛩️ CodeDojo // Cyberpunk Study Tracker

A full-featured, single-page study tracker with a dark, cyberpunk-inspired aesthetic.

## 🚀 Deployment Instructions

To make this website reachable by anyone, follow these steps:

### Option 1: Vercel (Recommended - Fastest)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory.
3. Follow the prompts to ship your site to a public `.vercel.app` URL.

### Option 2: GitHub Pages (Free Hosting)
1. Create a new repository on [GitHub](https://github.com/new).
2. Run the following commands:
   ```bash
   git init
   git add .
   git commit -m "Initial commit to the Dojo"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. Go to **Settings > Pages** on your GitHub repo and select the `main` branch.

### Option 3: Netlify Drop (No Code)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder onto the page.
3. Your site is live!
